# Road Accident Severity Prediction

A machine learning application that predicts road accident severity using a Random Forest Classifier.

## Prediction Classes

- Minor
- Major
- Fatal

## Machine Learning Algorithm

Random Forest Classifier

## Features

The model uses accident, road, traffic, weather and environmental features.

## Note

This project is an experimental machine-learning prototype and should not be used as a substitute for professional road-safety assessment.
